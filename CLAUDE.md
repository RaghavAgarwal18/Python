# Fork of TheAlgorithms/Python (CS440 Lab 6)

This is a **fork**. We practice contributing to an issue here, but we never
contribute to the upstream project (TheAlgorithms/Python).

## Rules
- Follow `CONTRIBUTING.md` for every change. Read it before writing code.
- Never push to `upstream`. Never open a pull request against TheAlgorithms/Python.
  Pull requests go to **this fork's own `master` branch**.
- One issue = one branch = one small pull request.
- Do not edit `README.md` or `DIRECTORY.md` (CONTRIBUTING.md says they are autogenerated).

## Code features
- Skill `contribute-to-issue`: the full workflow from reproducing the issue to opening the PR in the fork.
- Hook `block_upstream.py` (before Bash commands): blocks pushes and PRs aimed at upstream.
- Hook `check_contribution.py` (after edits): runs `ruff check`, `ruff format --check`, and the doctests.
- Sub-agent `contribution-reviewer`: reviews the diff against the CONTRIBUTING.md checklist.
